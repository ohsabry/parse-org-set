# parse-org-set

Extract the sounds inside [ORG 24](https://sofeh.com) `.Set` files as WAV files.

## Development

Requires [Bun](https://bun.sh).

    bun install
    bun run fmt   # format everything (Prettier)
    bun run lint  # check the code (ESLint)
